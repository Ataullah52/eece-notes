# EECE Notes
Exam-focused EECE study notes (PUST). Static site on GitHub Pages with three levels: **semester (eece11-eece42) → subject → topic**. Each topic page has theory, definitions, memorize points, examples and previous-year questions by priority; print any page to PDF with the button at the top.

Structure: `curriculum.json` lists semesters, subjects and topics; notes are `<semester>/<subject>/unit-NN-name.html`; `python3 build_index.py` regenerates all index pages. AI helpers: read AI_SPEC.md and AI_INDEX.md first.
