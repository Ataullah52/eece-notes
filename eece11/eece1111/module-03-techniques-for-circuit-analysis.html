Supernode & Supermesh Constraint Equations

★★★★★ 01. Definition & Law · Class Note · Lecture 07 (Professor’s Supernode & Supermesh Rules)

  • A Supernode encloses a floating voltage source between two non-reference nodes
  • a Supermesh bypasses a current source shared by two adjacent meshes.
  • When a voltage source (independent or dependent) is connected between two non-reference nodes, the current through that voltage source is unknown, preventing a standalone KCL equation at either node.
  • Enclose both nodes and the voltage source inside a dashed surface called a Supernode.
  • Similarly, when a current source lies on the boundary shared by two meshes, exclude the shared branch to form a single outer KVL loop (Supermesh), and write the current source relation at the shared branch.
Table 3.1 — Comparison of Supernode vs. Supermesh Formulations
FeatureSupernode (Nodal Analysis)Supermesh (Mesh Analysis)
Triggering ElementVoltage source between two non-reference nodesCurrent source shared between two meshes
Equation 1 (Conservation)Apply KCL across the outer Supernode boundaryApply KVL around the combined outer Supermesh perimeter
Equation 2 (Constraint)Apply KVL inside the Supernode: \(v_{p}lus - v_{\min}us = V_{s}ource\)Apply KCL at the shared branch: \(i_{m}esh2 - i_{m}esh1 = I_{s}ource\)

Class tip: Each Supernode reduces the number of required KCL equations by 1 (replaced by 1 simple voltage constraint equation). Never write KCL at an individual node inside a Supernode alone!

Nodal Analysis with a Floating Supernode & Dependent Source

★★★★ 02. Previous Year Question (PYQ) · Previous Year Question · Final Exam 2023 Q3(b) & 2021 Q3(a) · Asked in: 2023, 2021 (7 Marks)

  • Solve for node voltages \(v_{1}\) and \(v_{2}\) when a 10 V source connects Node 1 and Node 2.
Problem / Theorem Question
  • In a two-node circuit with reference ground at the bottom, an independent current source of 2 A enters Node \(1, a 2 \Omega \) resistor connects Node 1 to ground, \(a 4 \Omega \) resistor connects Node 2 to ground, \(a 10 \Omega \) resistor lies in parallel with a 10 V voltage source (+ terminal at Node 1, − terminal at Node 2), and a 7 A current source leaves Node 2. Find node voltages \(v_{1}\) and \(v_{2}\).

Given parameters

  • Current entering Node \(1: I_{in} = 2 A\); Current leaving Node \(2: I_{out} = 7 A\)
  • Shunt resistors to ground: \(R_{1} = 2 \Omega \) (at Node \(1), R_{2} = 4 \Omega \) (at Node 2)
  • Supernode voltage source: \(v_{1} - v_{2} = 10 V\)
Step 1: Discard the \(10 \Omega \) resistor in parallel with the ideal 10 V source during Supernode KCL

Any resistor connected strictly between the two nodes of a Supernode has its current both leaving and re-entering the same Supernode surface, canceling out in KCL:

\(\sum i_{e}ntering = \sum i_{l}eaving\)

\(\implies 2 = (\frac{v_{1}}{2}) + (\frac{v_{2}}{4}) + 7\)

Step 2: Simplify the Supernode KCL equation

Multiply through by 4 to clear fractions:

\(2v_{1} + v_{2} = -20\) (Equation 1)

Step 3: Apply the Supernode voltage constraint and solve

Substitute \(v_{1} = v_{2} + 10\) into Equation 1:

\(2(v_{2} + 10) + v_{2} = -20\)

\(\implies 3v_{2} = -40\)

\(\implies v_{2} = -13.33 V\)

\(v_{1} = -13.33 + 10\)

\(= -3.33 V\)

∴ \(v_{1} = -3.33 V, v_{2} = -13.33 V\)

Source Transformation & Nodal/Mesh Equations by Inspection

★★★ 03. Core Theory & Concept · Professor-Followed Book · Alexander & Sadiku (6th Ed.), Ch. 3 & Ch. 4

  • A practical voltage source \(V_{s}\) in series with \(R\) converts to an equivalent current source \(I_{s} = \frac{V_{s}}{R}\) in parallel with \(R\).
  • Source Transformation replaces a voltage source \(v_{s}\) in series with a resistor \(R\) by a current source \(i_{s} = \frac{v_{s}}{R}\) in parallel with the same resistor \(R\) (or vice versa), preserving terminal \(v-i\) characteristics.
  • When a linear resistive network contains no dependent sources, the Nodal Conductance Matrix \([G][v] = [i]\) and Mesh Resistance Matrix \([R][i] = [v]\) are symmetric and can be written directly by inspection.
Source Transformation Equivalence (Applies to both independent and dependent sources)
\(v_{s} = i_{s} \cdot R ⟺ i_{s} = \frac{v_{s}}{R}\)

Cramer’s Rule Solution for 2-Mesh Network with Dependent CCVS

★ 04. Worked Numerical Example · Syllabus Book · R. C. Dorf & J. A. Svoboda (Introduction to Electric Circuits, Ch. 4)

  • Move all dependent source terms involving mesh currents to the left-hand resistance matrix before applying Cramer’s Rule.
Problem / Theorem Question
  • A two-mesh circuit has Mesh 1 with a 20 V source, \(a 2 \Omega \) series resistor, and a shared \(4 \Omega \) resistor with Mesh 2. Mesh 2 contains the shared \(4 \Omega \) resistor, \(a 6 \Omega \) resistor, and a dependent voltage source \(2i_{1}\) opposing \(i_{2}\). Find mesh currents \(i_{1}\) and \(i_{2}\).
Step 1: Write KVL for Mesh 1 and Mesh 2

Group coefficients of \(i_{1}\) and \(i_{2}\):

Mesh \(1: 6i_{1} - 4i_{2} = 20\)

Mesh \(2: -2i_{1} + 10i_{2} = 0\)

\(\implies i_{1} = 5i_{2}\)

Substituting \(i_{1} = 5i_{2}\) into Mesh 1:

\(6(5i_{2}) - 4i_{2} = 20\)

\(\implies 26i_{2} = 20\)

∴ \(i_{2} = \frac{10}{13} \approx 0.77 A, i_{1} = \frac{50}{13} \approx 3.85 A\)
