Standard Equations of Sphere, Right Circular Cone, Right Circular Cylinder & 3D Quadric Surfaces

P1 · Class Note · Memorize & Quick Recall · Class Note · Units 22–24 (Sphere, Right Circular Cone/Cylinder & 3D Quadric Surfaces)

General sphere \(S \equiv x^{2} + y^{2} + z^{2} + 2ux + 2vy + 2wz + d = 0\) has center \(C = (-u, -v, -w)\) and radius \(R = \sqrt{u^{2} + v^{2} + w^{2} - d}\). Plane section at distance \(p < R\) is a circle of radius \(r = \sqrt{R^{2} - p^{2}}\).

General Sphere Equation, Center, Radius & Plane Section Circle
\(C = (-u, -v, -w), R = \sqrt{u^{2} + v^{2} + w^{2} - d} |\) Circle radius \(r = \sqrt{R^{2} - p^{2}} |\) Family: \(S + \lambda P = 0\)
Diameter Form & Orthogonal Spheres Condition
\((x - x_{1})(x - x_{2}) + (y - y_{1})(y - y_{2}) + (z - z_{1})(z - z_{2}) = 0 |\) Orthogonal: \(2u_{1}u_{2} + 2v_{1}v_{2} + 2w_{1}w_{2} = d_{1} + d_{2}\)
Right Circular Cone (Vertex \((\alpha , \beta , \gamma )\), Axis DRs (l, m, n), Semi-Vertical Angle \(\theta \))
\([l(x - \alpha ) + m(y - \beta ) + n(z - \gamma )]^{2} = (l^{2} + m^{2} + n^{2})[(x - \alpha )^{2} + (y - \beta )^{2} + (z - \gamma )^{2}] \cos^{2}\theta \)
Right Circular Cylinder (Axis through \((\alpha , \beta , \gamma )\) with DRs (l, m, n) and Radius \(R\))
\((x - \alpha )^{2} + (y - \beta )^{2} + (z - \gamma )^{2} - [l(x - \alpha ) + m(y - \beta ) + n(z - \gamma )]\frac{^{2}}{l^{2} + m^{2} + n^{2}} = R^{2}\)

PUST Past Exam Questions on Sphere Plane Sections (Circle Center & Radius) & Spheres Through a Circle

P2 · Previous Year Question + P1 · Previous Year Question · Previous Year Question · PUST EECE 2022–23, 2021–22 & 2020–21 Semester Final Exams [5 Marks] · Asked in: 2022–23, 2021–22, 2020–21 (5 Marks)

Find circle center \(N\) as the foot of the normal from sphere center \(C\) to the cutting plane, and use \(S + \lambda P = 0\) for spheres passing through a circle.

Problem / Theorem Question

(1) [PUST Past Exam — 5 Marks] Find the center and radius of the circle \(x^{2} + y^{2} + z^{2} - 2y - 4z - 11 = 0, x + 2y + 2z = 15\).

(2) [PUST Past Exam — 5 Marks] Find the equations of the spheres through the circle \(x^{2} + y^{2} + z^{2} = 5, x + 2y + 3z = 3\) that touch the plane \(4x + 3y = 15\).

Step-by-step solution
1. Center & Radius of Circle of Intersection

Find sphere center \(C\), sphere radius \(R\), perpendicular distance \(p\) to the plane, and foot of perpendicular \(N\):

Sphere center: \(C = (0, 1, 2)\), Sphere radius: \(R = \sqrt{0 + 1 + 4 + 11}\)

\(= 4\)

Distance from \(C(0, 1, 2)\) to plane \(x + 2y + 2z - 15 = 0\):

\(p = |0 + 2(1) + 2(2) - \frac{15|}{3}\)

\(= 3\)

\(\implies \) Circle radius, \(r = \sqrt{R^{2} - p^{2}}\)

\(= \sqrt{16 - 9}\)

\(= \sqrt{7}\)

Normal line \(N = (t, 2t + 1, 2t + 2)\) on \(x + 2y + 2z\)

\(= 15\) gives \(t\)

\(= 1\):

∴ Circle Center \(N = (1, 3, 4)\), Circle Radius \(r = \sqrt{7}\)

2. Spheres Through a Circle Touching a Given Plane

Form \(S + \lambda P = 0\) and equate perpendicular distance from center to radius:

Sphere family \(S + \lambda P = 0\):

\(x^{2} + y^{2} + z^{2} + \lambda x + 2\lambda y + 3\lambda z - (5 + 3\lambda ) = 0\)

Center \(C = (-\frac{\lambda }{2}, -\lambda , -\frac{3\lambda }{2})\), Radius \(R = \sqrt{\frac{7\lambda ^{2}}{2} + 3\lambda + 5}\)

Tangency condition to \(4x + 3y - 15 = 0\):

\((\lambda + 3)^{2} = \frac{7\lambda ^{2}}{2} + 3\lambda + 5\)

\(\implies 5\lambda ^{2} - 6\lambda - 8 = 0 \implies \lambda = 2, -\frac{4}{5}\)

∴ Spheres: \(x^{2} + y^{2} + z^{2} + 2x + 4y + 6z - 11 = 0\) and \(5(x^{2} + y^{2} + z^{2}) - 4x - 8y - 12z - 13 = 0\)

PUST Past Exam Questions on Guiding-Curve Cone, Right Circular Cylinder & 3D Conicoid Reduction

P2 · Previous Year Question + P1 · Previous Year Question · Previous Year Question · PUST EECE 2022–23, 2021–22 & 2020–21 Semester Final Exams [5–7 Marks] · Asked in: 2022–23, 2021–22, 2020–21 (5–7 Marks)

Complete exam derivations for cones with a given vertex and guiding curve, right circular cylinders, and 3D central conicoid reduction.

Problem / Theorem Question

(1) [PUST Past Exam — 5 Marks] Find the cone with vertex (1, 2, 3) and guiding curve \(x^{2} + y^{2} = 4, z = 0\).

(2) [PUST Past Exam — 5 Marks] Find the right circular cylinder of radius \(R = 2\) with axis \(\frac{x - 1}{2} = \frac{y - 2}{1} = \frac{z - 3}{2}\).

(3) [PUST Past Exam — 7 Marks] Reduce \(2x^{2} - 7y^{2} + 2z^{2} - 10yz - 8zx - 10xy + 6x + 12y - 6z + 2 = 0\) to standard form.

Step-by-step solution
1. Cone with Vertex (1, 2, 3) & Guiding Circle \(x^{2} + y^{2} = 4, z = 0\)

Write generator through (1, 2, 3), intersect with \(z = 0\), and eliminate l, m, n:

Generator through \((1, 2, 3): \frac{x - 1}{l} = \frac{y - 2}{m}\)

\(= \frac{z - 3}{n}\)

At \(z = 0: x = 1 - \frac{3l}{n}, y = 2 - \frac{3m}{n}\)

Substituting into \(x^{2} + y^{2} = 4\) and using \(\frac{l}{n} = \frac{x - 1}{z - 3}, \frac{m}{n} = \frac{y - 2}{z - 3}\):

\((z - 3x)^{2} + (2z - 3y)^{2} = 4(z - 3)^{2}\)

∴ \(9x^{2} + 9y^{2} + z^{2} - 6xz - 12yz + 24z - 36 = 0\)

2. Right Circular Cylinder of Radius \(R = 2\)

Apply the cylinder projection formula with point (1, 2, 3) and axis DRs (2, 1, 2):

\((x - 1)^{2} + (y - 2)^{2} + (z - 3)^{2} - [2(x - 1) + 1(y - 2) + 2(z - 3)]\frac{^{2}}{9} = 2^{2}\)

\(\implies 9[(x - 1)^{2} + (y - 2)^{2} + (z - 3)^{2}] - (2x + y + 2z - 10)^{2} = 36\)

∴ \(5x^{2} + 8y^{2} + 5z^{2} - 4xy - 4yz - 8zx + 22x - 16y - 14z + 26 = 0\)

3. Reduction of 3D Conicoid (Corrected Eigenvalues & Center for Problem 24.1)

Solve \(\det(A - \lambda I) = 0\) for eigenvalues \(\lambda _{1}, \lambda _{2}, \lambda _{3}\) and \(\frac{\frac{1}{2}\partial F}{\partial x} = \frac{\frac{1}{2}\partial F}{\partial y} = \frac{\frac{1}{2}\partial F}{\partial z} = 0\) for center:

Discriminating cubic \(\det(A - \lambda I) = 0\):

\(\lambda ^{3} + 3\lambda ^{2} - 90\lambda + 216 = 0\)

\(\implies (\lambda - 6)(\lambda - 3)(\lambda + 12) = 0 \implies \lambda _{1} = 6, \lambda _{2} = 3, \lambda _{3} = -12\)

Center equations:

\(2\alpha - 5\beta - 4\gamma + 3 = 0, -5\alpha - 7\beta - 5\gamma + 6 = 0, -4\alpha - 5\beta + 2\gamma - 3 = 0\)

\(\implies \) Center \((\alpha , \beta , \gamma ) = (\frac{1}{3}, -\frac{1}{3}, \frac{4}{3}), d' = u\alpha + v\beta + w\gamma + d\)

\(= -3\)

\(\implies 6X^{2} + 3Y^{2} - 12Z^{2} - 3 = 0\)

∴ \(2X^{2} + Y^{2} - 4Z^{2} = 1\) (Hyperboloid of One Sheet)

Rahman & Bhattacharjee Worked Problems: Sphere Through Four Points & Mutually Perpendicular Cone Generators

P3 · Professor-Followed Book · Worked Numerical Example · Professor-Followed Book · Rahman & Bhattacharjee (3D Geometry: Sphere & Cone)

A homogeneous second-degree cone \(ax^{2} + by^{2} + cz^{2} + 2fyz + 2gzx + 2hxy = 0\) has sets of three mutually perpendicular generators iff \(a + b + c = 0\).

Problem / Theorem Question

(1) [Rahman & Bhattacharjee] Find the equation of the sphere passing through the origin (0, 0, 0) and the three axial intercepts (a, 0, 0), (0, b, 0), (0, 0, c).

(2) Find the equation of the cone with vertex at the origin (0, 0, 0) that passes through the circle \(x^{2} + y^{2} + z^{2} + 2ux + d = 0\), lx + my + nz \(= p\).

Step-by-step solution
1. Sphere Through (0, 0, 0), (a, 0, 0), (0, b, 0), (0, 0, c)

Substitute the four points into \(x^{2} + y^{2} + z^{2} + 2ux + 2vy + 2wz + d = 0\):

At \((0, 0, 0): d = 0\)

At \((a, 0, 0): a^{2} + 2ua = 0\)

\(\implies 2u = -a\)

At \((0, b, 0): b^{2} + 2vb = 0\)

\(\implies 2v = -b\)

At \((0, 0, c): c^{2} + 2wc = 0\)

\(\implies 2w = -c\)

∴ \(x^{2} + y^{2} + z^{2} -\) ax − by − cz \(= 0\)

2. Homogenizing Sphere & Plane to Form Cone with Vertex at (0, 0, 0)

Use \(1 =\) (lx + my + nz) / p to make the sphere equation homogeneous of degree 2:

Given sphere: \(x^{2} + y^{2} + z^{2} + 2ux(1) + d(1)^{2} = 0\)

Substituting \(1 =\) (lx + my + nz) / p:

∴ \(p^{2}(x^{2} + y^{2} + z^{2}) + 2upx\)(lx + my + nz) + d(lx + my + nz)\(^{2} = 0\)

Syllabus Book Problems: Radical Plane, Limiting Points of Coaxial Spheres & Enveloping Cone \(SS_{1} = T^{2}\)

P4 · Syllabus Book · Worked Numerical Example · Syllabus Book · E. H. Askwith & G. B. Thomas & R. L. Finney (Quadric Surfaces)

The tangent cone (enveloping cone) from an external point \(P(x_{1}, y_{1}, z_{1})\) to a sphere \(S = 0\) is given by \(SS_{1} = T^{2}\).

Enveloping Cone from \((x_{1}, y_{1}, z_{1}) \&\) Radical Plane of Two Spheres
Enveloping Cone: \(S \cdot S_{1} = T^{2} |\) Radical Plane: \(S_{1} - S_{2} = 0\)
Problem / Theorem Question

(1) [Askwith] Find the limiting points of the coaxial system of spheres determined by \(S_{1} \equiv x^{2} + y^{2} + z^{2} - 8x - 2y - 4z + 15 = 0\) and \(S_{2} \equiv x^{2} + y^{2} + z^{2} - 2x + 4y + 2z + 9 = 0\).

(2) Find the enveloping cone of the sphere \(x^{2} + y^{2} + z^{2} = 4\) with vertex at (1, 1, 3).

Step-by-step solution
1. Limiting Points of Coaxial System of Spheres

Find the radical plane \(S_{1} - S_{2} = 0\) and set radius \(R^{2} = 0\) in \(S_{1} + \frac{2\lambda (S_{1} - S_{2})}{6} = 0\):

Radical plane \(S_{1} - S_{2} = 0\):

\(-6x - 6y - 6z + 6 = 0 \iff x + y + z - 1 = 0\)

Coaxial sphere family \(S_{1} + 2\lambda (x + y + z - 1) = 0\):

Center \(C = (4 - \lambda , 1 - \lambda , 2 - \lambda )\)

Radius \(R^{2} = (4 - \lambda )^{2} + (1 - \lambda )^{2} + (2 - \lambda )^{2} - (15 - 2\lambda )\)

\(= 3\lambda ^{2} - 12\lambda + 6\)

\(= 0\)

\(\implies \lambda = 2 \pm \sqrt{2}\)

∴ Limiting Points: \((2 \mp \sqrt{2}, -1 \mp \sqrt{2}, \mp \sqrt{2})\)

2. Enveloping Cone of \(x^{2} + y^{2} + z^{2} - 4 = 0\) from Vertex (1, 1, 3)

Apply \(SS_{1} = T^{2}\) with \(S_{1} = 1^{2} + 1^{2} + 3^{2} - 4 = 7\) and \(T = x + y + 3z - 4\):

Here \(S = x^{2} + y^{2} + z^{2} - 4, S_{1} = 1 + 1 + 9 - 4\)

\(= 7, T = x + y + 3z - 4\)

Using \(S \cdot S_{1} = T^{2}\):

\(7(x^{2} + y^{2} + z^{2} - 4) = (x + y + 3z - 4)^{2}\)

∴ \(6x^{2} + 6y^{2} - 2z^{2} - 2xy - 6yz - 6zx + 8x + 8y + 24z - 44 = 0\)
