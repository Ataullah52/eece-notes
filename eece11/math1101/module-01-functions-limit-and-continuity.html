Definition of a Function, Classification & Class Lecture Domain/Range Problems

★★★★★ 01. Definition & Law · Class Note · Unit 1 (Concept of Function, Classification, Domain & Range)

  • If for every permissible input \(x \in D\) there corresponds one and only one finite real output \(y\), then \(y = f(x)\) is a function of \(x\).
  • A function \(y = f(x)\) assigns to each input \(x\) in the domain \(D_{f}\) a unique finite real number \(y\) in the range \(R_{f}\).
  • For example, \(y = x^{2} + 1\) is a valid function \((x = 1 \implies y = 2; x = 2 \implies y = 5)\).
  • Whereas \(y^{2} = x \implies y = \pm \sqrt{x}\) is not a function because a single input \(x = 4\) produces two distinct outputs \(y = +2\) and \(y = -2\).
  • A function can be expressed in four ways:
  • (1) Analytically/Algebraically by a formula
  • (2) Numerically by a table of values
  • (3) Geometrically by its graph in the xy-plane
  • (4) Verbally in plain language.
1. Rational Function Domain Rule
\(f(x) = \frac{P(x)}{Q(x)} \implies \) Defined when \(Q(x) \neq 0\)
  • Exclude all real zeros of the denominator \(Q(x)\)
2. Even Root in Numerator
\(f(x) = \sqrt{g(x)} \implies \) Defined when \(g(x) \ge 0\)
  • Boundary zeros where \(g(x) = 0\) are included
3. Even Root in Denominator
\(f(x) = \frac{1}{\sqrt{g(x)}} \implies \) Defined when \(g(x) > 0\)
  • Strict inequality since denominator cannot be zero
4. Logarithmic Function Domain Rule
\(f(x) = \ln(g(x)) \implies \) Defined when \(g(x) > 0\)
  • Argument of a logarithm must be strictly positive
5. Inverse Trigonometric Function Domain Rule
\(f(x) = \sin^{-1}(g(x))\) or \(\cos^{-1}(g(x)) \implies \) Defined when \(-1 \le g(x) \le 1\)
  • Principal inverse sine and cosine domain restriction

Problem / Theorem Question
  • Find the domain and range of the following Class Lecture & Homework functions:
  • (1) \(f(x) = \frac{1}{x - 3}\)
  • (2) \(f(x) = \sqrt{x^{2} - 5x + 6}\) and \(g(x) = \frac{1}{\sqrt{x^{2} - 5x + 6}}\)
  • (3) \(f(x) = \sqrt{\frac{x - 2}{3 - x}}\)
Problem 1.1 (Class Lecture): \(f(x) = \frac{1}{x - 3}\)

Exclude the denominator zero for Domain, then solve for \(x\) in terms of \(y\) for Range:

Step 1 (Domain):

Given, \(f(x) = \frac{1}{x - 3}\)

Denominator \(\neq 0\):

\(x - 3 = 0\)

\(\implies x = 3\) [Excluded point]

∴ Domain, \(D_{f} = \mathbb{R} \setminus \{3\} = (-\infty , 3) \cup (3, \infty )\)

Step 2 (Range):

Let \(y = \frac{1}{x - 3}\)

\(\implies x - 3 = \frac{1}{y}\)

\(\implies x = \frac{1 + 3y}{y}\) [Undefined when \(y = 0\)]

∴ Range, \(R_{f} = \mathbb{R} \setminus \{0\} = (-\infty , 0) \cup (0, \infty )\)

Problem 1.2 & 1.5 (Class Lecture): \(f(x) = \sqrt{x^{2} - 5x + 6}\) and \(g(x) = \frac{1}{\sqrt{x^{2} - 5x + 6}}\)

Factor the quadratic inside the square root and test interval signs across critical points \(x = 2, 3\):

For \(f(x) = \sqrt{x^{2} - 5x + 6}\):

\(f(x) = \sqrt{(x - 2)(x - 3)}\)

For real values, radicand \(\ge 0\):

\(x^{2} - 5x + 6 \ge 0\)

\(\implies (x - 2)(x - 3) \ge 0\) [Critical points: \(x = 2, 3\)]

Sign analysis:

• On \((-\infty , 2): (-) \times (-) = +\) (Valid)

• On \((2, 3): (+) \times (-) = -\) (Invalid)

• On \((3, \infty ): (+) \times (+) = +\) (Valid)

Checking endpoints: \(f(2) = 0\) and \(f(3) = 0\) are defined.

∴ Domain, \(D_{f} = (-\infty , 2] \cup [3, \infty )\)

∴ Range, \(R_{f} = [0, \infty )\)

For \(g(x) = \frac{1}{\sqrt{x^{2} - 5x + 6}}\):

Since the radical is in the denominator, strict inequality holds:

\((x - 2)(x - 3) > 0\)

∴ Domain, \(D_{g} = (-\infty , 2) \cup (3, \infty )\)

∴ Range, \(R_{g} = (0, \infty )\)

Problem 1.4 (Class Homework): \(f(x) = \sqrt{\frac{x - 2}{3 - x}}\)

Enforce non-negative radicand \(\frac{x - 2}{3 - x} \ge 0\) and non-zero denominator \(3 - x \neq 0\):

Step 1 (Domain):

\(\frac{x - 2}{3 - x} \ge 0\) and \(3 - x \neq 0\)

Sign of \(\frac{x - 2}{3 - x}\):

• On \((-\infty , 2): \frac{-}{+} = -\) (Invalid)

• On \((2, 3): \frac{+}{+} = +\) (Valid)

• On \((3, \infty ): \frac{+}{-} = -\) (Invalid)

At \(x = 2\):

\(f(2) = \sqrt{\frac{0}{1}}\)

\(= 0\) (Included)

At \(x = 3\):

\(f(3) = \sqrt{\frac{1}{0}}\) (Undefined, excluded)

∴ Domain, \(D_{f} = [2, 3)\)

Step 2 (Range):

Let \(y = \sqrt{\frac{x - 2}{3 - x}}\) where \(y \ge 0\)

\(\implies y^{2} = \frac{x - 2}{3 - x}\)

\(\implies 3y^{2} - xy^{2} = x - 2\)

\(\implies x(1 + y^{2}) = 3y^{2} + 2\)

\(\implies x = \frac{3y^{2} + 2}{y^{2} + 1}\) [Defined for all real \(y \ge 0\)]

∴ Range, \(R_{f} = [0, \infty )\)

1. PUST EECE 2020–21 Q1(a) [5 Marks]: \(f(x) = \frac{x - 2}{3 - x}\)

Find the excluded denominator zero for Domain, then express \(x\) in terms of \(y\) for Range:

Step 1 (Domain):

Given, \(f(x) = \frac{x - 2}{3 - x}\)

For \(f(x)\) to be real and finite, denominator \(\neq 0\):

\(3 - x = 0\)

\(\implies x = 3\) [Excluded point]

∴ Domain, \(D_{f} = \mathbb{R} \setminus \{3\} = (-\infty , 3) \cup (3, \infty )\)

Step 2 (Range):

Let \(y = \frac{x - 2}{3 - x}\)

\(\implies y(3 - x) = x - 2\)

\(\implies 3y -\) xy \(= x - 2\)

\(\implies x +\) xy \(= 3y + 2\)

\(\implies x(1 + y) = 3y + 2\)

\(\implies x = \frac{3y + 2}{y + 1}\) [Undefined when \(y + 1 = 0 \implies y = -1\)]

∴ Range, \(R_{f} = \mathbb{R} \setminus \{-1\} = (-\infty , -1) \cup (-1, \infty )\)

2. PUST EECE 2021–22 Q1(a) [5 Marks]: \(f(x) = \sqrt{16 - x^{2}}\)

Determine the domain, range, and geometric locus of the upper semicircle:

For Domain:

\(16 - x^{2} \ge 0\)

\(\implies x^{2} \le 16\)

\(\implies -4 \le x \le 4\)

∴ Domain, \(D_{f} = [-4, 4]\)

For Range:

Since \(x \in [-4, 4]\):

\(0 \le x^{2} \le 16\)

\(\implies 0 \le 16 - x^{2} \le 16\)

\(\implies 0 \le \sqrt{16 - x^{2}} \le 4\)

∴ Range, \(R_{f} = [0, 4]\)

Graph Description:

\(y = \sqrt{16 - x^{2}} (y \ge 0)\)

\(\iff x^{2} + y^{2} = 4^{2} (y \ge 0)\)

which is the upper semicircle centered at (0, 0) with radius \(r = 4\).

3. PUST EECE 2022–23 Q1(a) [4 Marks]: Piecewise Function Domain & Range

Analyze each branch over its interval to determine the combined domain and range:

Branch \(1 (x < 0)\):

\(y = x^{2} + 1\) is the left half of an upward parabola approaching (0, 1) as \(x \to 0^{-}\)

and rising to \(+\infty \) as \(x \to -\infty \).

\(\implies y \in (1, \infty )\)

Branch \(2 (0 \le x \le 3)\):

\(y = 3x + 1\) is a line segment from (0, 1) to (3, 10).

\(\implies y \in [1, 10]\)

Branch \(3 (x > 3)\):

\(y = 10\) is a horizontal ray starting at (3, 10) extending to \(+\infty \).

\(\implies y = 10\)

Combining all three branches:

∴ Domain, \(D_{f} = (-\infty , 0) \cup [0, 3] \cup (3, \infty ) = \mathbb{R}\)

∴ Range, \(R_{f} = [1, \infty )\)

Vertical derivations for each function:

1. Ex. \(8: f(x) = \frac{1}{5x + 7}\)

\(5x + 7 \neq 0\)

\(\implies x \neq -\frac{7}{5}\)

∴ Domain, \(D_{f} = (-\infty , -\frac{7}{5}) \cup (-\frac{7}{5}, \infty )\)

∴ Range, \(R_{f} = (-\infty , 0) \cup (0, \infty )\)

2. Ex. \(9 \& 10: (a) g(x) = \sqrt{x^{2} - 3}\) and (b) \(g(x) = \sqrt{x^{2} + 3}\)

(a) \(x^{2} - 3 \ge 0\)

\(\implies |x| \ge \sqrt{3}\)

∴ Domain, \(D_{g} = (-\infty , -\sqrt{3}] \cup [\sqrt{3}, \infty )\)

∴ Range, \(R_{g} = [0, \infty )\)

(b) \(x^{2} + 3 \ge 3 > 0\) for all \(x \in \mathbb{R}\)

∴ Domain, \(D_{g} = (-\infty , \infty )\)

∴ Range, \(R_{g} = [\sqrt{3}, \infty )\)

3. Ex. \(12: h(x) = \sqrt{x - 3x^{2}}\)

\(x - 3x^{2} \ge 0\)

\(\implies x(1 - 3x) \ge 0\)

\(\implies 0 \le x \le \frac{1}{3}\)

Maximum of \(x - 3x^{2}\) occurs at vertex \(x = \frac{1}{6}\):

\(h(\frac{1}{6}) = \sqrt{\frac{1}{12}}\)

\(= \frac{1}{2\sqrt{3}}\)

∴ Domain, \(D_{h} = [0, \frac{1}{3}]\)

∴ Range, \(R_{h} = [0, \frac{1}{2\sqrt{3}}]\)

Completing the square and checking removable point discontinuities:

4. Ex. \(13: \varphi (x) = \frac{x}{|x| + 1}\)

∴ Domain, \(D_{\varphi } = (-\infty , \infty )\)

Part (B) — Anton Sec. 0.4 Inverse Function Derivations (Ex. 20, 23, 37)

Solve \(y = f(x)\) vertically for \(x\) in terms of \(y\), respecting domain restrictions:

(i) \(f(x) = \frac{x + 1}{x - 1}\):

Let \(y = \frac{x + 1}{x - 1}\)

\(\implies \) yx \(- y = x + 1\)

\(\implies x(y - 1) = y + 1\)

\(\implies x = \frac{y + 1}{y - 1}\)

∴ \(f^{-1}(x) = \frac{x + 1}{x - 1}, x \neq 1\)

(ii) \(f(x) = \frac{3}{x^{2}} (x < 0)\):

Let \(y = \frac{3}{x^{2}}, y > 0\)

\(\implies x^{2} = \frac{3}{y}\)

\(\implies x = -\sqrt{\frac{3}{y}}\) [Negative root chosen because \(x < 0\)]

∴ \(f^{-1}(x) = -\sqrt{\frac{3}{x}}, x > 0\)

(iii) \(f(x) = \frac{e^{x} + e^{-x}}{2} (x \ge 0)\):

Let \(y = \frac{e^{x} + e^{-x}}{2}\) [For \(x \ge 0, y \ge 1\)]

\(\implies 2y = e^{x} + \frac{1}{e^{x}}\)

\(\implies (e^{x})^{2} - 2y(e^{x}) + 1 = 0\) [Quadratic in \(e^{x}\)]

\(\implies e^{x} = \frac{2y \pm \sqrt{4y^{2} - 4}}{2}\)

\(= y \pm \sqrt{y^{2} - 1}\)

\(\implies e^{x} = y + \sqrt{y^{2} - 1}\) [Since \(x \ge 0 \implies e^{x} \ge 1\)]

\(\implies x = \ln(y + \sqrt{y^{2} - 1})\)

∴ \(f^{-1}(x) = \ln(x + \sqrt{x^{2} - 1}), x \ge 1\)

  • \(\lim\limits_{x\to a} f(x) = L\) exists if and only if both L.H.L. \(= \lim\limits_{x\to a^{-}} f(x)\) and R.H.L. \(= \lim\limits_{x\to a^{+}} f(x)\) exist finitely and are equal.

Two-Sided Limit Existence Criterion
L.H.L. \(= \lim\limits_{x\to a^{-}} f(x) = \lim\limits_{x\to a^{+}} f(x) =\) R.H.L. \(= L\)
Fundamental Trigonometric & Infinity Limits
\(\lim\limits_{x\to 0} \frac{\sin x}{x} = 1\)\(\lim\limits_{x\to 0} \frac{\tan x}{x} = 1\)\(\lim\limits_{x\to 0} \frac{1 - \cos x}{x} = 0\)\(\lim\limits_{x\to \pm \infty } \frac{1}{x^{n}} = 0 (n > 0)\)

1. Class Lecture Problem \(2.1: f(x) = 1 + |x - 1|\)

Split the absolute value at \(x = 1\) and identify the shifted V-shaped graph vertex:

\(|x - 1| = \{ 1 - x\), if \(x < 1; x - 1\), if \(x \ge 1 \}\)

Adding 1 to both branches:

\(f(x) = 1 + |x - 1| = \{ 2 - x\), if \(x < 1; x\), if \(x \ge 1 \}\)

Vertex is shifted 1 unit right and 1 unit up to (1, 1).

∴ Domain, \(D_{f} = (-\infty , \infty )\), Range, \(R_{f} = [1, \infty )\)

2. Class Lecture Problem 3.1 & 3.2: One-Sided Limits (L.H.L. vs R.H.L.)

Compare L.H.L. and R.H.L. at each boundary point:

Problem 3.1 (i) At \(x = 0\):

L.H.L. \(= \lim\limits_{x\to 0^{-}} (x^{2} + 5)\)

\(= 0^{2} + 5\)

\(= 5\)

R.H.L. \(= \lim\limits_{x\to 0^{+}} (x + 5)\)

\(= 0 + 5\)

\(= 5\)

∴ \(\lim\limits_{x\to 0} f(x) = 5\) (Exists)

Problem 3.1 (ii) At \(x = 3\):

L.H.L. \(= \lim\limits_{x\to 3^{-}} (x + 5)\)

\(= 3 + 5\)

\(= 8\)

R.H.L. \(= \lim\limits_{x\to 3^{+}} (2x + 1)\)

\(= 2(3) + 1\)

\(= 7\)

∴ Since L.H.L. (8) \(\neq \) R.H.L. \((7), \lim\limits_{x\to 3} f(x)\) does not exist.

Problem 3.2: Evaluate \(\lim\limits_{x\to 3} |x - \frac{3|}{x - 3}\):

L.H.L. \(= \lim\limits_{x\to 3^{-}} -\frac{x - 3}{x - 3}\)

\(= -1\)

R.H.L. \(= \lim\limits_{x\to 3^{+}} +\frac{x - 3}{x - 3}\)

\(= +1\)

∴ Since L.H.L. \((-1) \neq \) R.H.L. \((+1), \lim\limits_{x\to 3} |x - \frac{3|}{x - 3}\) does not exist.

3. Class Lecture Problem \(3.3: \lim\limits_{x\to \infty } (2x + 3)^{3}(3x - 2)\frac{^{2}}{x^{5} + 5}\)

Divide numerator and denominator by \(x^{5} = x^{3} \cdot x^{2}\):

\(L = \lim\limits_{x\to \infty } (2x + 3)^{3}(3x - 2)\frac{^{2}}{x^{5} + 5}\)

\(= \lim\limits_{x\to \infty } \frac{(2 + \frac{3}{x})^{3} (3 - \frac{2}{x})^{2}}{1 + \frac{5}{x^{5}}}\)

\(= (2 + 0)^{3} (3 - 0)\frac{^{2}}{1 + 0}\)

\(= 8 \times 9\)

∴ \(L = 72\)

1. PUST EECE 2020–21 Q1(c) [4.5 Marks]: Prove \(\lim\limits_{x\to 2}(3x - 5) = 1\)

Let \(\varepsilon > 0\) be arbitrary. Here \(f(x) = 3x - 5, a = 2\), and \(L = 1\). Find \(\delta > 0\) in terms of \(\varepsilon \):

Scratch / Backward Simplification:

\(|(3x - 5) - 1| < \varepsilon \) whenever \(0 < |x - 2| < \delta \)

\(\implies |3x - 6| < \varepsilon \)

\(\implies |3(x - 2)| < \varepsilon \)

\(\implies 3|x - 2| < \varepsilon \)

\(\implies |x - 2| < \frac{\varepsilon }{3}\)

Formal Deduction:

Choose \(\delta = \frac{\varepsilon }{3} > 0\).

Then whenever \(0 < |x - 2| < \delta \):

\(|(3x - 5) - 1| = |3x - 6|\)

\(= 3|x - 2|\)

\(< 3\delta [∵ |x - 2| < \delta ]\)

\(= 3(\frac{\varepsilon }{3})\)

\(= \varepsilon \)

∴ \(\lim\limits_{x\to 2}(3x - 5) = 1\) (with \(\delta = \frac{\varepsilon }{3}\))

2. PUST EECE 2022–23 Q1(b) [4.5 Marks]: Continuity at \(x = -1\) and \(x = 1\)

Enforce L.H.L. \(=\) R.H.L. \(= f(a)\) at the boundary points \(x = -1\) and \(x = 1\):

Step 1 (Continuity at \(x = -1\)):

L.H.L. \(= \lim\limits_{x\to -1^{-}} (-2)\)

\(= -2\)

R.H.L. \(= \lim\limits_{x\to -1^{+}}\) (ax − b)

\(= -a - b\)

Since L.H.L. \(=\) R.H.L.:

\(-a - b = -2\)

\(\implies a + b = 2 --- (1)\)

Step 2 (Continuity at \(x = 1\)):

L.H.L. \(= \lim\limits_{x\to 1^{-}}\) (ax − b)

\(= a - b\)

R.H.L. \(= \lim\limits_{x\to 1^{+}} (3)\)

\(= 3\)

Since L.H.L. \(=\) R.H.L.:

\(a - b = 3 --- (2)\)

Step 3 (Solving (1) and (2)):

Adding (1) and (2):

\(2a = 5\)

\(\implies a = \frac{5}{2}\)

From (1):

\(b = 2 - \frac{5}{2}\)

\(= -\frac{1}{2}\)

∴ \(a = \frac{5}{2}, b = -\frac{1}{2}\)

3. PUST EECE 2020–21 Q1(b) [4.5 Marks]: Continuity at \(x = 0\) and \(x = 1\)

Enforce continuity at \(x = 0\) and \(x = 1\):

At \(x = 0\):

L.H.L. \(= \lim\limits_{x\to 0^{-}} (x^{2} + 2)\)

\(= 2\)

R.H.L. \(= \lim\limits_{x\to 0^{+}}\) (ax + b)

\(= b\)

\(\implies b = 2\)

At \(x = 1\):

L.H.L. \(= \lim\limits_{x\to 1^{-}}\) (ax + b)

\(= a + b\)

R.H.L. \(= \lim\limits_{x\to 1^{+}} (3 + 2x - x^{2})\)

\(= 3 + 2 - 1\)

\(= 4\)

\(\implies a + b = 4\)

\(\implies a + 2 = 4\)

\(\implies a = 2\)

∴ \(a = 2, b = 2\)

2. Anton 1.3 Ex. 25, 26 & 32 (Radical Limits at \(\pm \infty \))

Syllabus Book Problems: Squeeze (Sandwich) Theorem, Exponential Jump Discontinuity & Non-Linear \(\varepsilon -\delta \) Proof

★ 07. Worked Numerical Example · Syllabus Book · G. B. Thomas & R. L. Finney (Ch. 1) & M. R. Spiegel (Advanced Calculus)

  • If \(g(x) \le f(x) \le h(x)\) near \(x =\) a and \(\lim\limits_{x\to a} g(x) = \lim\limits_{x\to a} h(x) = L\), then \(\lim\limits_{x\to a} f(x) = L\).
Squeeze (Sandwich) Theorem Criterion
\(g(x) \le f(x) \le h(x)\) and \(\lim\limits_{x\to a} g(x) = \lim\limits_{x\to a} h(x) = L \implies \lim\limits_{x\to a} f(x) = L\)
Bounded Oscillating Product Rule
\(\lim\limits_{x\to 0} x^{n} \sin(\frac{1}{x}) = 0\) and \(\lim\limits_{x\to 0} x^{n} \cos(\frac{1}{x}) = 0\) (for \(n > 0\))
Problem / Theorem Question
  • (1) [Thomas & Finney] Use the Squeeze Theorem to prove that \(\lim\limits_{x\to 0} x^{2} \sin(\frac{1}{x}) = 0\).
  • (2) [Spiegel, Advanced Calculus] Examine the continuity of \(f(x) = \frac{1}{1 + 2^{\frac{1}{x}}}\) at \(x = 0\).
  • (3) [\(F\). Ayres, Schaum’s Calculus] Prove using the \(\varepsilon -\delta \) definition that \(\lim\limits_{x\to 3} x^{2} = 9\).
1. Squeeze Theorem Proof: \(\lim\limits_{x\to 0} x^{2} \sin(\frac{1}{x}) = 0\)

Bound \(\sin(\frac{1}{x})\) between −1 and +1 for all \(x \neq 0\) and multiply by \(x^{2} > 0\):

For all \(x \neq 0\):

\(-1 \le \sin(\frac{1}{x}) \le 1\)

\(\implies -x^{2} \le x^{2} \sin(\frac{1}{x}) \le x^{2} [∵ x^{2} > 0]\)

Taking limits as \(x \to 0\):

\(\lim\limits_{x\to 0} (-x^{2}) = 0\) and \(\lim\limits_{x\to 0} (+x^{2}) = 0\)

∴ By the Squeeze Theorem, \(\lim\limits_{x\to 0} x^{2} \sin(\frac{1}{x}) = 0\)

2. Exponential Jump Discontinuity at \(x = 0: f(x) = \frac{1}{1 + 2^{\frac{1}{x}}}\)

Evaluate \(\frac{1}{x} \to -\infty \) as \(x \to 0^{-}\) and \(\frac{1}{x} \to +\infty \) as \(x \to 0^{+}\):

As \(x \to 0^{-}: \frac{1}{x} \to -\infty \)

\(\implies 2^{\frac{1}{x}} \to 0\)

L.H.L. \(= \lim\limits_{x\to 0^{-}} \frac{1}{1 + 2^{\frac{1}{x}}}\)

\(= \frac{1}{1 + 0}\)

\(= 1\)

As \(x \to 0^{+}: \frac{1}{x} \to +\infty \)

\(\implies 2^{\frac{1}{x}} \to +\infty \)

R.H.L. \(= \lim\limits_{x\to 0^{+}} \frac{1}{1 + 2^{\frac{1}{x}}}\)

\(= 0\)

∴ Since L.H.L. (1) \(\neq \) R.H.L. \((0), f(x)\) has a finite jump discontinuity at \(x = 0\).

3. Non-Linear \(\varepsilon -\delta \) Proof: \(\lim\limits_{x\to 3} x^{2} = 9\)

Restrict \(\delta \le 1\) so that \(|x + 3| < 7\), then choose \(\delta = \min(1, \frac{\varepsilon }{7})\):

We have:

\(|x^{2} - 9| = |x + 3| \cdot |x - 3|\)

First restrict \(\delta \le 1\):

\(|x - 3| < 1\)

\(\implies 2 < x < 4\)

\(\implies 5 < x + 3 < 7\)

\(\implies |x + 3| < 7\)

Choose \(\delta = \min(1, \frac{\varepsilon }{7}) > 0\).

Then whenever \(0 < |x - 3| < \delta \):

\(|x^{2} - 9| = |x + 3| \cdot |x - 3|\)

\(< 7 \cdot (\frac{\varepsilon }{7})\)

\(= \varepsilon \)

∴ \(\lim\limits_{x\to 3} x^{2} = 9\) (with \(\delta = \min(1, \frac{\varepsilon }{7})\))
